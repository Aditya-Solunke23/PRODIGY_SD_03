# 👥 Simple Contact Management System

A simple contact management system developed as part of Task 03 of my Software Development Internship at Prodigy InfoTech.

## Task Objective

Develop a program that allows users to store and manage contact information.

The application allows users to add, view, edit, search, and delete contacts containing a name, phone number, and email address.

## Features

- Add new contacts
- View all saved contacts
- Edit existing contacts
- Delete contacts
- Search contacts by name, phone number, or email
- Form validation
- Persistent storage using browser localStorage
- Contact count
- Responsive user interface
- Confirmation before deleting contacts

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## Data Storage

The application uses the browser's `localStorage` to persist contact information.

This means contacts remain available after refreshing the page or reopening the browser on the same device.

## How to Use

### Add Contact

1. Enter the contact's name.
2. Enter their phone number.
3. Enter their email address.
4. Click **Add Contact**.

### Edit Contact

Click the **Edit** button next to an existing contact.

Modify the required information and click **Update Contact**.

### Delete Contact

Click **Delete** next to a contact and confirm the deletion.

### Search

Use the search box to search contacts by:

- Name
- Phone number
- Email address

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in a browser.

Alternatively, use the Live Server extension in Visual Studio Code.
